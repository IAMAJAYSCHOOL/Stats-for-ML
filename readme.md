# Statistics for Machine Learning and Data Science Lab

This repository contains Jupyter Notebook implementations of the experiments performed for the **Statistics for Machine Learning and Data Science Lab (2015111)**.

The experiments are implemented in Python using Jupyter Notebook and include statistical analysis, data preprocessing, visualization, machine learning, and related techniques.

## Tools and Libraries

* Python 3.x
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SciPy
* Scikit-learn

## Dataset

Most experiments use the **Pima Indians Diabetes Dataset**.

Make sure the required dataset file, such as `diabetes.csv`, is available in the same directory as the Jupyter Notebook before running it.

## How to Open and Run the Notebooks

### Option 1: Run Locally Using Jupyter Notebook

1. Clone this repository:

```bash
git clone <repository-url>
```

2. Open the repository folder:

```bash
cd <repository-folder>
```

3. Install Jupyter Notebook if it is not already installed:

```bash
pip install notebook
```

4. Install the required libraries:

```bash
pip install pandas numpy matplotlib seaborn scipy scikit-learn
```

5. Start Jupyter Notebook:

```bash
jupyter notebook
```

6. Open the required `.ipynb` file from the Jupyter interface.

7. Run the cells one by one using:

```text
Shift + Enter
```

Or run the complete notebook using:

```text
Kernel → Restart Kernel and Run All Cells
```

## Option 2: Open Directly on GitHub

The notebooks can also be viewed directly on GitHub.

1. Open the required `.ipynb` file.
2. GitHub will automatically display the notebook code and saved outputs.

> Note: GitHub allows viewing notebooks but does not execute the code.

## Important Notes

* Ensure that all required dataset files are present before running the notebooks.
* Run the cells in sequence to avoid variable or import errors.
* Install all required Python libraries before execution.
* Some experiments may require additional libraries depending on the statistical or machine learning techniques used.
